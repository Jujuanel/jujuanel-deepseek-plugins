# DeepSeek 网页油猴脚本

## 会话一键删除

文件：`deepseek-quick-delete.user.js`

- 侧栏每个会话左侧显示与网页 Delete 菜单相同的 SVG 删除图标。
- 点击图标直接删除对应会话，不显示确认弹窗。
- 按 `Command+D` 直接删除当前打开的会话，输入框有焦点、侧栏折叠时同样有效。
- 新会话、置顶会话和滚动加载的会话自动添加图标。
- 删除非当前会话时保留当前页面；删除当前会话时使用网站原生跳转行为。
- 连续点击和按键长按不会触发重复删除。

### 安装

在 Chrome 的 Tampermonkey（油猴）中新建脚本，将该文件的完整内容粘贴进去，保存后刷新 `https://chat.deepseek.com/`。

### 实现与限制

使用网站原生菜单及删除按钮，在脚本触发的删除过程中隐藏菜单和确认弹窗并自动确认。无需读取凭据或调用私有接口。网页结构发生变化或删除失败时显示错误提示，并恢复原生弹窗的可见性。

已有菜单或弹窗打开时，先关闭它再使用一键删除。仅拦截 `Command+D`，不拦截带 Shift、Option 或 Control 的组合键。
